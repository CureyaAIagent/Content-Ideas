- Calendar: table with date, platform, pillar, hook, format, CTA.
- Post: hook, body in short lines, CTA. Bullet lists for social posts.
- Weekly report: top posts, reach, engagement rate, three lessons, three tests for next week.

Rules:
- Write short sentences. Use active voice. Use data and examples.
- One idea per post.
- Draft only. A human approves before publishing.
- Cite the source for every statistic.
